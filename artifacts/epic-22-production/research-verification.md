Research date: 2026-10-16. Scope: Epic #22 / #39; no inference, crawl, code mutations, or confidence calibration experiment. Reviewed saved issues #22/#39, spec/plan/tasks, `_evidence.py`, `monitor/snapshot.py`, export entry points, existing provenance/resolution/monitor/export tests.

## Primary sources and their actual implications

1. **Standard — [W3C PROV-DM](https://www.w3.org/TR/prov-dm/)**. Provenance records entities, activities, derivations, attribution and bundles; it supports assessments of trustworthiness rather than proving factual truth. Engineering application: preserve original captured entities, normalization transformations, competing observations and resolution policy as separate records. Stable IDs must remain stable through a restart and bundle round trip. Do not call source-role assertions independent manufacturer verification. No RDF migration is necessary for this epic.
2. **Standard — [RFC 6901, JSON Pointer](https://www.rfc-editor.org/rfc/rfc6901)**. Standardized paths identify members of a JSON document; escaped slash and tilde and array indexing have defined semantics. Engineering application: retained pointers must resolve against their own retained payload, not today's web response; test `/attributes/a~1b~0c`, variant indexes, empty-root pointer, malformed escapes and missing targets. A URL alone does not satisfy offline retrieval.
3. **W3C Group Note — [Data Quality Vocabulary](https://www.w3.org/TR/vocab-dqv/)**. Quality measurements have metrics and provenance; quality depends on use and dimensions such as availability and accuracy differ. Engineering application: report bounded fixture evidence coverage separately from correctness or calibration. Persist the report's fixture IDs, policy version, fixed UTC evaluation time and command. Do not label retrieval coverage as extraction accuracy.
4. **Research paper — [Guo et al., On Calibration of Modern Neural Networks, ICML 2017](https://proceedings.mlr.press/v70/guo17a.html)**. Model probability/confidence estimates can be miscalibrated; calibration is evaluated against empirical correctness. Engineering application: a rule/model score is not validated confidence. Require the existing method/dataset/version metadata for `ValidatedConfidence`; tests demonstrate metadata preservation, not empirical calibration. No calibration claim is justified by this fixture suite.
5. **Research paper — [El-Yaniv and Wiener, On the Foundations of Noise-free Selective Classification, JMLR 2010](https://www.jmlr.org/papers/v11/el-yaniv10a.html)**. Selective classification formalizes abstention and a coverage/risk tradeoff under its assumptions. Engineering application: explicit unsupported/unknown/conflicting outcomes are useful; this product is not implementing that classifier or inheriting its statistical guarantees. State vocabulary and retention thresholds remain project design choices.

These sources motivate auditability and abstention; they do not establish the project's 24-hour/30-day TTLs, source ranking, SQLite design, or support-state names. Those are versioned engineering policies. An ACM artifact-policy page returned HTTP 403 and was not used; no additional source sweep is needed.

## Existing integration hazards

- `snapshot()` currently serializes `asdict(product)` and stringifies Decimal/datetime. The dynamic evidence contract intentionally does not appear in dataclass `asdict`; #37 must explicitly persist it. Existing snapshot scalar compatibility must remain intact.
- Existing exporters accept lists of dictionaries. #38 must expose an explicit portable path or opt-in companion, preserving established CSV/feed shapes. Bare matching evidence IDs cannot resolve without the source contract.
- `TrustContract.to_dict()/from_dict()` already preserve tagged Decimal/datetime and validate duplicate IDs, dangling IDs and resolutions. Reuse these rather than generic JSON coercion.
- Freshness expiry in #36 keeps original observations/evidence and changes the resolution. Retention expiry in #37 may remove captured support. These are separate events and must not silently recreate an observed fact from a stale cached resolution.
- Product scalars remain compatibility values. A trust report must display `trust_view()` values/states; unsupported scalar defaults such as price zero must never be presented as trusted facts.

## Bounded offline fixture matrix

Use one small captured supplier payload and manufacturer payload, a fixed aware UTC `as_of`, deterministic IDs where fixtures are hand-authored, and temporary SQLite/files. One offline extraction adapter exercised through the normal extraction/normalization route is sufficient; unit/regression tests already cover other adapters. Network calls must fail the example/test if attempted.

SC-01's denominator is **every factual path in these bounded fixtures**, computed with `factual_paths`, including nested variants/containers. For each path require an explicit supported state with independently retrievable retained evidence, or an explicit unavailable state with reason. Do not count serialized IDs alone as retrievable evidence. SC-02 additionally checks all original alternatives, not just that one winner exists. SC-03 compares semantic typed representations rather than JSON byte order. Run before and after expiry separately; expiry is an intentional semantic transition.
