## Risks and decisions for G1
- Index parsing/acquisition must bound input URLs, pages, response bytes, memberships, redirects/pagination and total duration; never browse or recursively infer categories. Distinguish HTTP failures/budget exhaustion from complete coverage.
- Anchor selection must be inside main listing product cards, excluding navigation/footer and recommendations. Same URL may belong to multiple categories; dedupe category/product pairs, not products globally.
- Scope must include origin and configured store base path. Reject credentials, non-HTTP schemes, encoded traversal and cross-origin redirects/next links. URL matching should retain meaningful query distinctions; fragment removal is appropriate but broad path/slug guessing is not.
- Reindexing mixed image lists can invalidate retained evidence; preserve or remap source paths explicitly. Placeholder recognition should use well-defined URL path segments/file names, not arbitrary substring matching.
- Portable index is untrusted input: validate record types/version/limits/scope and capture consistency. Caller-supplied capture remains unverified-source evidence, never manufacturer authority.
- Environment has enforced restricted networking and Naheed is outside the reported allowlist; live requests must be recorded blocked unless policy changes. Deterministic MockTransport and synthetic HTML verify production mechanisms only.
