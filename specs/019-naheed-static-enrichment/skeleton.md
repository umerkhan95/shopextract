# G2 interface declarations
No runtime stubs needed; tests exercise concrete interfaces once implemented.

- extractors/_product_html.py: `usable_image(value) -> bool`, `clean_product_images(product) -> None`, `enrich_product_html(products: list[dict], html: str, url: str) -> None`. Single-product DOM only; image representations string/list/ImageObject preserved where possible. Reindexed list elements bind `_field_sources` to original capture positions. DOM projection uses capture(method='html_product_dom', excerpt=selected DOM), with each changed normalizer input path mapped to exact captured value. Existing capture and structured nonempty brand/SKU/images win. Relative DOM image URLs resolved against fetched URL; unsafe schemes ignored. Product DOM selectors MagicZoom/MagicZoomPlus/data-zoom-id galleries, `.brand-name a`, `span.sku`; never arbitrary image/link scanning. OG raw gains brand/sku/image gallery and additive normalizer support.
- unified.py: call shared enrichment before HTTP fast-path check and after browser product/OG layering; helper completeness/media selection must reject placeholders.
- _detect.py: Magento module and RequireJS asset signatures added to HTML probe; fallback generic confidence 0.
- categories/listings.py: `listing_urls(content: bytes) -> list[str]` bounded XML urlset or JSON string-list (<=1MiB, <=1000 URLs); `async build_listing_index(urls, store_url, *, client=None, max_pages=20, max_memberships=1000, page_bytes=1048576) -> dict`; `validate_listing_index(index, store_url) -> None`; `with_listing_categories(raw, index) -> dict`; `observe_listing_categories(raw, *, context) -> tuple[CategoryObservation,...]`.
- Index v1 shape exact top keys: schema_version=1, store_url, pages_visited integer, complete bool, reasons list[str], memberships list[dict]. Each membership exact keys: product_url, category_url, label (str or None), _capture. Capture method html_category_listing; values /product_url, /category_url, /label match row; excerpt holds bounded original heading/card HTML. Each source capture URL is fetched listing URL. Positive membership namespace merchant:listing_category, native ID category URL, label only when heading present. No parent edges. Observer completeness unknown on successful index, partial on interrupted index. Terms/refs bounded by existing category limits.
- Acquisition: sequential GETs only, timeout15 per request; max_pages1..1000, max_memberships1..10000, page_bytes1..1048576; <=1000 input URLs; same origin and store base path, no credentials or traversal including encoded forms. Own client disables redirects; injected client final response URL checked. Only `.products-grid .product-item a.product-item-link` / `.products-list .product-item a.product-item-link` in main (or body without main) qualify, and ancestors `.block.related,.block.upsell,.block.crosssell,aside,nav,footer` disqualify. Next from main toolbar pager `.pages a.next` or `a[rel=next]`, scoped and cycle-deduped. Query distinctions retained; fragments stripped. Dedup pair(category URL,product URL), keep multiple categories. Missing heading means label None. HTTP errors, blocked redirects, oversize/invalid/nonlisting documents and budget reached become reasons+complete false; no negative membership inference. Root category identity remains the input URL across pagination; visited pages separately retain source URL.
- categories/api.py: append listing observer only when `listing_categories` carrier exists; use existing final shared term bounding. Helper copies raw, adds listing_categories and exact per-field `_field_sources`; original source capture unchanged; scope validated before attach.
- _cli_categories.py: `categories index-listings FILE --options OPTIONS [--output INDEX] [--max-pages N] [--max-memberships N] [--timeout S]`; FILE is XML sitemap or JSON URLs. `categories normalize FILE --options OPTIONS [--listing-index INDEX]`; absent flag stays unchanged. Existing scoped options/atomic JSON/1MiB output and execution timeout wrappers reused. Partial acquisition writes useful positive artifact but returns E_PARTIAL.

Failure contracts: invalid caller/index types, version, scope, inconsistent captures or limits raise CategoryError (CLI E_USAGE). Remote failures return partial index, never fabricated success. No background/browser/LLM work.
