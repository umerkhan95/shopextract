# Reusable component model
Existing capture() and _field_sources own bounded source retention and support checks. New HTML helper only selects DOM, filters known placeholders and supplies exact per-field capture bindings. Unified static/browser paths share it. Normalizer retains conversion ownership (including new additive OG brand/SKU/gallery fields); image truth is not duplicated across callers.
Existing httpx transport and category contracts own requests and facts. listings.py is one bounded source-specific parser/index, not a generic crawler framework: it has two consumers (index CLI and normalize-with-index helper). Existing category API appends its observation then applies shared budgets. Existing exact mapper, category source_fact, merchant_scope/observation_id, validate_observations and portable codecs remain unchanged.
CLI reuses CategoryOptions validation, safe timeout/execution wrapper, atomic artifact publication, standard error envelopes and 1MiB bounds. No registration system, new dependency, new model constructor, inference/browser fallback or background lifecycle.
