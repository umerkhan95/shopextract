# Concrete P3 reuse ownership
CoreGroup remains sole bootstrap/error owner; CoreCommand registered leaves and canonical tuples in _MACHINE_COMMANDS activate only implemented machine leaves. Plain Click evidence/bundle/sidecar groups reuse registered-child scanner; no parser reimplementation. Existing cli functions retain legacy default dispatch and positional argument order; reviewed additive options delegate _cli_monitor.
_cli_data read_json_file/load_products/atomic_json/product_to_record bound typed transport. _cli_analysis output/report reused for envelopes/native recursive dicts; explicit P3 change/lookup fields avoid arbitrary dataclass dumping. Evidence.to_dict? Actual Evidence encoded via explicit dataclass field list with encode_value; TrustContract.to_dict is native. New datetime encoded by encode_value. No generic conversion framework.
Native monitor.snapshot owns extraction and save_snapshot; optional retention adds metadata only. Native watch owns interval/alerts and snapshot lifecycle; wrapper owns finite whole-operation timeout/max-events/aclose and context policy. _cli_extract.run_operation is snapshot policy/deadline wrapper; watch needs custom consumer to emit JSONL and final partial result. Shared validate_url/max/timeout reused.
Native changes/_detect_changes/history retain comparison/identity lookup ownership; additive read_only branches use URI reader, migration prerequisite rather than silently initializing. Native evidence owns graph storage/lookup/retention; readonly load/get reuse _load_snapshot/_read_capture. Preview copies existing SQLite into in-memory connection and invokes exactly existing prune calculation via private connection parameter; only one algorithm and original DB remains read-only.
Native reliable_changes owns comparator/ledger/replay/recheck/transaction rollback. CLI readonly preflight only IDs/supplier/order/scope (no comparison duplication). Native identity migrate_snapshot_identities(conn) retains migration transaction and applies explicit CLI intent; no pretend preview. Native resolve_fields/resolution_references operate product and variants; no authority inference.
Native create/load/read/write_evidence_bundle own validation/codecs; CLI file creation stages native write and validates native read then replace. Existing atomic_json publishes sidecar/load result. P2 output companion helper already calls same create_evidence_sidecar; P3 standalone exposes it with payload bytes bound1MiB. No library algorithms copied. Each new CLI helper has present concrete callers (DB readers, artifacts, policy/time loaders).
Watch lifecycle revision: one optional native on_initialized notification is consumed by finite CLI terminal state only; native snapshot still owns successful persistence, classic comparator still owns events, CLI labels scalar output unverified. No second scheduling/comparison algorithm.
