# P5 operations and integrated delivery specification

## Outcomes and requirements
P5-FR01 (parent FR02/08/09): root maintenance composes native durable store/engine with required explicit --db; create, status (alias show), list, run, resume, cancel, retry, report, evidence. No merchant write operation exists: create/run/cancel/retry mutate only the explicitly selected local database and command invocation authorizes that mutation. No fictitious merchant apply/dry-run. Native module entrypoints stay unchanged. Goal schema_version string 1.0; profiles wrapper integer1; category runtime uses native codec. Validate inputs before opening DB. Unknown jobs never create a DB. Run/resume/retry require bounded --timeout (default30, max120), one native worker, native two-attempt retry ceiling and goal budgets/deadline. Tokens/cost cannot invoke an investigator via CLI. Report pagination explicit offset/limit; list has limit/offset. Expose native category-policy composition and shipped/custom profiles.
P5-FR02 (FR08/09): tools schemas is static native inventory of exactly eight schemas, with native version explicit. tools serve --config trusted-operator.json is protocol-only stdio; root output settings/config/environment do not format or validate protocol frames. Usage/config/dependency failures go to stderr, never an outer envelope. Missing extra says install shopextract[mcp]. Native module invocation retained.
P5-FR03 (FR08/09): tools call --config FILE --request FILE --timeout 1..120 executes one bounded session, closes/reaps runtime in finally. Request string-version1.0 closed object steps1..32; each closed {id,tool,arguments}; distinct ids; tool bootstrap, poll, pages or one of eight native names. Only literal JSON arguments and {$ref:"earlier-id#/json/pointer"} references allowed. No callbacks/eval/config imports. Native handle/session/origin restrictions preserved. poll args job_id, interval_seconds .01..1 default .05; pages args native job_result plus max_pages1..10 default10; native schemas/bounds validated before each dispatch. Max1MiB final response: failure never silently truncates. pages stops at max_pages with explicit partial/exit3 and cursor; bounded session deadline cleans children. Bootstrap yields native captures/owners. Session handles are invalid in another invocation; maintenance IDs durable.
P5-FR04 (FR01/03/10): capabilities introspects real Click grammar, complete options/defaults/argument arity/choices, output contract and command paths. schema list/show serves packaged response/config and supported file input schemas, native tool schemas with distinct envelope versions, versioned capability inventory. Discovery/help starts no runtime. No actual command retains deferred phase guard. Preserve nine legacy defaults.
P5-FR05 (FR01/10): final native API inventory reconciled to actual commands/options/helpers; README/docs/examples/config/migration accurate. Genuine wheel installed outside checkout proves all command help, packaged schemas and documented offline examples. Full CI-equivalent groups and genuine SDK protocol/native durable subprocess checks mandatory.

## Acceptance scenarios
P5-SC01 durable create in process1, status/report/cancel/resume in later processes; explicit DB isolated, goal invalid/unknown job no file creation; zero product budget returns partial without network. Native retry misuse rejected, native unknown replay covered by existing store tests.
P5-SC02 schema inventory lazy; exactly8 native names; serve ignores hostile ambient response setting and produces only SDK frames. Missing SDK actionable stderr.
P5-SC03 real ToolRuntime bootstrap captured snapshot, match submit/poll/pages via prior-result refs, evidence lookup, cross-invocation stale handle rejected. Config origins cannot be expanded by request. Page bounded partial explicit. Cleanup on timeout/error/interruption.
P5-SC04 capabilities exactly reflects installed grammar, all leaf output contracts; schema resources importable from wheel, strict unsupported schema errors. All-phase public API mapping classified.
P5-SC05 malformed/duplicate/unknown/version/bool/numeric config/request/goal boundaries reject before DB/network; response limits do not leak payload or secrets. Crossphase input schemas/native category composition remain intact.
P5-SC06 full regression groups, wheel/module/console help parity and README examples. Public live probes unnecessary for P5; actual SDK + durable local processes required offline.

## Boundaries and compatibility
No model launch/download/paid inference, no remote daemon, no executable configuration. Parent 30HTTP/12items/300s budget unchanged. Protocol exemption explicitly documented. Parent response version1.0 independent of native tool response version1.0 and CLI/profile config integer1.

## Exact P5 session and file contracts (G1 dispositions)
Tools operator config preserves native unversioned closed object optional allowed_origins:string[], allowed_tools:8-name[], captures:{alias,db_path,snapshot_id,supplier}[], limits:native Limits fields. The packaged schema documents this deliberate native compatibility exception; CLI config remains integer1 and request/goal string1.0. Captures have positive integer snapshot_id and nonempty strings. Lists reject scalar strings/booleans; unknown fields rejected. Limits use exact positive native integer/number types, finite and <=native defaults; active_jobs=1. Custom profiles file is closed {schema_version:1,profiles:{name:{field:{kind,role,normalization?}}}}; kind/role and defaults native FieldRule. Goal is native Goal closed object (baseline,supplier_origin,product_urls,deadline required; schema_version explicitly required1.0); native defaults/limits and supplied/captured validation retained. Category-config is native CategoryRuntimeConfig record (native unversioned), no new codec.
Tools session output is {session_only:true,steps:[{id,tool,result}],completeness:"complete"|"partial"}. Each result is exactly native envelope for native tools, bootstrap raw native {schema_version,captures,limits}, poll last native job_status envelope, pages {pages:[native job_result envelopes],next_cursor:string|null,complete:boolean}. refs resolve against prior step RESULT (not row): boot#/captures/0/catalog_handle, match#/data/job_id, pages#/next_cursor. Every native failed envelope stops with E_OPERATION and safe fixed native error code in message; no native arguments echoed. poll exits only on succeeded; failed/cancelled/timed_out -> E_OPERATION (session deadline -> E_TIMEOUT). pages arguments closed {job_id,collection,page_size?,cursor?,max_pages?}; uses native job_result schema for first4 fields, defaults page_size20,max_pages10. It polls job status first, drains up to max_pages, preserves total/metadata/completeness/native cursor. Any native partial page or remaining cursor makes outer E_PARTIAL/exit3 with session data. poll args closed {job_id,interval_seconds?}, default .05, .01..1. bootstrap arguments closed empty {}. Helpers preserve original native framing where specified. All errors/partial close runtime.
Example request: {"schema_version":"1.0","steps":[{"id":"boot","tool":"bootstrap","arguments":{}},{"id":"matched","tool":"match","arguments":{"schema_version":"1.0","left_catalog":{"$ref":"boot#/captures/0/catalog_handle"},"right_catalog":{"$ref":"boot#/captures/0/catalog_handle"}}},{"id":"done","tool":"poll","arguments":{"job_id":{"$ref":"matched#/data/job_id"}}},{"id":"rows","tool":"pages","arguments":{"job_id":{"$ref":"matched#/data/job_id"},"collection":"matches","page_size":10,"max_pages":2}}]}.
Maintenance timeout is E_TIMEOUT/exit1, retryable true, after native cancellation/close/release; persisted running job becomes cancelled. SIGINT is E_CANCELLED/exit130, persisted running job cancelled, cleanup completes before response. A cancelled job's resume obeys native terminal-state behavior, never silently restarts a terminal job; user creates a new goal if native resume refuses/reports terminal. Parent unknown-outcome partial jobs remain explicitly retryable only by native retry step. Implement timeout with separately observed elapsed task deadline: native run consuming cancellation cannot turn a timeout into success.
