# P1 interfaces (G2)

`_execution.py`: immutable ExecutionPolicy(browser:bool=False,llm:LLMBudget|None=None,secrets:tuple[str,...]=()); LLMBudget(model,key,temperature,max_calls,max_output_tokens,max_input_bytes); contextmanager execution_policy(policy), current_policy(), browser_allowed(); async bounded_llm(urls,budget)->list[dict]. Policy overrides native ambient resolution; no public signature changes. Native `_try_llm_extraction` delegates bounded route when policy set, returns empty when disabled. `_extract.extract` skips env overrides while policy set. `_browser.get_browser_config` rejects disabled launch; unified/discovery skip unavailable escalation without discarding parsed HTTP facts. Completion request bounds applied before provider; HTTP stream input bounded before provider call.

`_cli_data.py`: read_json_file(path:str)->object (1MiB/depth64/nodes100000); raw_records(value)->list[dict]; load_products(path)->list[Product] native portable decode for concrete later P2/P3 consumers; extraction_data(result)->dict uses native portable records; atomic_json(path,data)->None. No generic arbitrary dataclass codec. Known credential redaction applied solely error/diagnostic strings; captured source facts remain untouched.

`_cli_extract.py`: validate/bind named typed options (no dynamic function lookup); run bounded coroutine inside execution_policy with asyncio.wait_for; emit_result(data,partial=False) uses P0 make_response/emit_response and Exit3. New command callbacks normalize/quality/feed/extract-one; cli.py root declarations own Click interface; existing `_extract`/`_discover` route new/machine mode to binding. Detect deadline wraps existing native callback. Explicit options detected via Click parameter source, not comparing values to defaults. LLM-only options require allow-llm. Browser optin preflight uses existing executable path without launch.

Error paths: invalid file/options CliFailure E_USAGE; missing browser/dependency E_DEPENDENCY; deadline TimeoutError maps P0 E_TIMEOUT; native partial E_PARTIAL retained data; interrupt native asyncio cleanup then P0 E_CANCELLED. Atomic output writes sibling temporary, os.replace after encode success, cleanup on failure. Preserve P0 handler invocation ordering/closed config.

G2 acceptance tests exercise actual command discovery/declarations and strict codecs. Before implementation absent new commands/flags fail directly, saved red. Detailed provider/HTTP tests added against these seams after G3, no algorithm stubs.

G2 accounting refinement: `ExecutionState(policy, deadline:float, llm_calls:int=0)` is per-operation mutable owned state stored in ContextVar; `execution_policy(policy,timeout)` creates state with monotonic deadline and resets token finally. Child async tasks share the same state; `bounded_llm` checks/increments calls immediately before each provider await (no intervening await between check/increment), uses max(remaining deadline) for HTTP/provider timeouts. Repeated/nested helpers consume the same allowance; no per-helper reset. Sequential helper execution, cancellation retains consumed count until context exit. Native helpers outside a policy retain legacy behavior.
