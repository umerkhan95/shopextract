# P0 design plan

Scope: exact core grammar/config/envelope/error contracts, legacy baseline and
complete local symbol classification. Constitution: additive opt-in behavior;
no identity/evidence/extraction default changes; no paid gate or model activation.

Use spec.md/test-design.md first, then tasks.md/research.md and independent G1.
Next stages: skeleton and genuine red evidence / G2; reused components / G3;
bounded implementation; actual mechanism/stress/regression verification; final
independent review. No later phase grammar is approved by a reserved target map.

The future core seams are limited to config selection/strict decoding, machine
response serialization, error routing and Click registration/help handling. Typed
signatures/module ownership are G2 work; components are G3 work, not authored as
already approved. Root cli.py remains registration boundary. One sequential agent,
no runtime/inference/network work in this design. See verification.md for actual
checks and status.md for resume point. Independent G1 passed design-only; see reviews.md. Runtime gates remain pending.
