## Narrow new components and why they are shared

- **contracts:** one schema/envelope/error/serializer authority used by Python runtime, MCP adapter, cursor validation and runnable examples. Owns strict types/version/error priority, never permission or I/O. Public defaults in Limits remain explicit, not inferred from dataclass coercion.
- **OperationContext:** carries the one job ID, enqueue-based absolute deadline, cancellation event, cumulative budget, source receipt timestamp and session-owned auxiliary slot through domain → sources → guard/transport/backend → process owner. Needed by both candidate screening and socket-time resolution and by native fallback/redirect paths; never replaced by per-call relative timeout. Data declarations exist; accounting/lifecycle algorithms await implementation.
- **SessionStore/RetainedGraph:** one owner of immutable ordered result collections, catalog/capture/product/variant handles, exact evidence references and byte charge. Concrete consumers are job_result, evidence, match, changes and bootstrap. Shared captures counted once/job and conservatively across jobs; 4MiB full graph/job and 32MiB/session. Publication reserves/commits atomically; expiry/eviction/cancel/disconnect invalidate all derived handles and release exact charge. Configured-capture materializations count here; no separate hidden cache.
- **JobManager:** one bounded state machine for four background operations and status/cancel/result calls. Publishes terminal state and graph under one winner; status does not extend retention. Queued deadline starts at enqueue; cancellation before acknowledgement cannot orphan work. One active job/8 queued/32 terminal, finite TTL. No durable orchestrator/scheduler introduced.
- **OwnedProcess:** one session auxiliary slot shared by blocking system DNS and existing synchronous domain work; bounded bytes in/out, late-reply discard, terminate/kill/reap cleanup <=1s, fail-closed shutdown if unreaped. Distinct from JobManager because sources need the same slot during connection setup; no worker pool or thread offload. It owns process lifetime; domain/guard own semantics, never a child permission update.
- **SourceGuard/GuardedTransport/PinnedBackend:** source policy before input/candidate/redirect, raw HTTP caps before decode, and vetted address selection at actual TCP connection. These are separate seams because an origin filter alone cannot stop DNS rebinding and a byte counter after decoding cannot bound allocation. One per-job context/pool; exact startup source authority is immutable. Test resolver/raw-wire boundaries are trusted constructor injection only, unavailable via MCP/client/page data.
- **DomainAdapter:** thin consumers of existing components, not an alternative extraction/matching/report engine. Converts native outputs to immutable graph/collections and exposes completeness/errors truthfully. Owns which existing function runs; ownership lookup/session policy stay in SessionStore/runtime.
- **MCP adapter/reference client:** adapter delegates business validation/calls to ToolRuntime, advertises only enabled tools, wraps envelopes in SDK result types. Cleanup uses try/finally even on SDK error/cancel/disconnect. Client proves genuine transport integration and uses bounded lifecycle/pagination/evidence sequence, never internal dispatcher calls. No remote hosting/auth layer required.

## Lifecycle, failure and coupling rules

Trusted startup configuration creates runtime/session; config/capture grants cannot originate in scraped text. Submit validates schema/tool/source permission, creates context once and queues work. Network operations use guarded origin/DNS/connection and raw body bounds; candidate source eligibility does not skip later DNS checks. Synchronous native work owns exactly one disposable child; resolver/domain lifetimes serialize. Worker error/cancel/timeout cleans auxiliary/pool before terminal publication and releases unpublished graph/bytes. Success commits reserved immutable graph and handles. Pages/evidence reuse retained graph without refetch/recompare; active operations validate dependency ownership/lifetime before execution and immediately before publication; expiry before publication fails expired and discards unpublished results. Any temporary input copy is charged to that active job/session, never an unaccounted pin or TTL extension. No cache can silently keep evicted evidence accessible.

Ownership failures use indistinguishable not_found, not path/ID disclosure. Transport failures are source_error or truthful incomplete data, not empty-success by exception catch. Oversize encoding/body/graph errors release resources; absence of payload is explicit and never invented support. One child's crash cannot permit another job to publish stale data; transaction cleanup/rollback and deterministic replay use real existing persistence paths in planned tests. Cleanup failure stops admission/server rather than accumulating orphan children.

Dependency arrows remain adapter → runtime → contracts/jobs/state/domain; domain → existing algorithms and sources; sources → guard/transport/execution. Legacy APIs never import runtime/MCP. No new shared component without a named consumer above; don't add a generic plugin/fetch/model orchestration framework. Exact module boundaries may be combined for cohesion only if typed ownership and reviewed test seams stay intact.
