## Typed public boundary

Declared in tools/runtime.py: frozen Limits, CaptureGrant(alias:str, db_path:str, snapshot_id:int, supplier:str), ToolConfig(allowed_origins:tuple[str,...], allowed_tools:tuple[str,...], captures:tuple[CaptureGrant,...], limits:Limits). Config validation must reject unsupported higher limits/types, normalize origins and freeze nested authority; frozen dataclass alone is insufficient. Capture paths/IDs stay trusted startup-only.

`ToolRuntime(config, *, resolver=None, wire_transport=None, clock=None)` owns one session. Injection is trusted in-process constructor seam, never tool/env input; default production resolver/transport always guarded. Async `call(name:str, arguments:Mapping[str,Any])->dict[str,Any]`; `tool_schemas()->list[dict]` returns MCP Tool-compatible name/description/inputSchema/outputSchema; `bootstrap()->dict` returns bounded granted capture aliases/opaque handles and safe operating metadata, never paths; async `aclose()->None` is idempotent owned teardown. Constructor creates no network/worker; bootstrap materializes/charges configured captures lazily or fails resource_limit. MCP server configuration is CLI/operator input, never source content.

Envelope success TypedDict: `{schema_version: Literal['1.0'], request_id: str, ok: Literal[True], data: JsonObject, warnings: list[Diagnostic]}`. Failure: same fields with `ok:False`, `error:{code:ErrorCode,message:str,retryable:bool,details?:JsonObject}`, no data. Diagnostic `{code:str,message:str,source_url?:str}` never embeds raw text/credentials. JsonValue is null/bool/int/finite-float/string/list/str-key-object; price/confidence money facts use canonical decimal strings where existing serializer supports decimal. Typed internal ToolError carries code/safe details; generic unexpected exception maps internal_error without repr/trace. MCP protocol errors remain protocol errors; valid tool requests with domain failures return domain envelope with isError=True and structuredContent, plus equivalent JSON text for simple clients.

Every argument object has required `schema_version:'1.0'`, `additionalProperties:false`, strict types, no coercion of bool into ints. Version error precedes fetch, schema errors precede ownership lookup; unauthorized valid handles return indistinguishable not_found. Tool input shapes:

| Tool | Required domain fields | Optional fields / output data |
| --- | --- | --- |
| discover | url:str | max_items:int=20 (1..1000), timeout_seconds:number=30 (1..120); job acknowledgement |
| extract | url:str | same caps; job acknowledgement |
| match | left_catalog:str, right_catalog:str | timeout_seconds; job acknowledgement; pair comparisons capped by bounded catalogs and total work limit, no network |
| changes | previous_capture:str, current_capture:str | recheck_capture:str, timeout_seconds; job acknowledgement; supplier derived/validated from grants, never arbitrary DB path |
| evidence | owner:str, evidence_id:str | available metadata/retained support, or explicit retention state; no network |
| job_status | job_id:str | state, queued_at, started_at?, terminal_at?, expires_at?, safe error?, result summary? |
| job_result | job_id:str, collection:str | page_size:int=20 (1..100), cursor:str; paged result below |
| job_cancel | job_id:str | terminal or cancelling state; deterministic winner, repeated cancel idempotent |

Acknowledgement `{job_id,state:'queued'|'running'}`. Terminal states succeeded/failed/cancelled/timed_out. Job state transitions spec-authoritative; unfinished result `{state}` has no fabricated items; terminal failures return error envelope. Successful page `{state:'succeeded',collection,items:list,next_cursor:str|null,total:int,completeness:str,metadata:JsonObject}`; metadata includes catalog_handle for extraction, report identity/policy for changes. Collections urls/products/matches/candidates/events/new_events/diagnostics are declared per operation, unknown collection invalid_argument. Oversize evidence returns resource_limit with safe inspectable metadata in details, no false complete payload. Invalid handles are never parsed as server paths.

## Modules and dependency seams (planned, not fabricated runtime code)

- contracts.py: strict JSON schemas, serializer/decoder and ToolError. Existing monitor/_portable evidence/product serialization reused; typed JSON envelope shared by direct API and MCP. No source requests.
- runtime.py: dispatcher owns ToolConfig, SessionStore, JobManager and DomainAdapter; checks exact tool permission before work and exposes trusted bootstrap grants. `call` validates → authorizes → submits or reads/cancels. All scoped IDs opaque and session-bound.
- state.py: `SessionStore.reserve(graph:RetainedGraph)->OwnedHandle`, `release(job_id)`, `lookup(owner_handle)->OwnerGraph`, `page(job_id,collection,page_size,cursor)->Page`. RetainedGraph contains immutable ordered collections, metadata, product/variant ownership graph, observation/evidence/capture table and deterministic full UTF-8 serialized-byte charge. Shared capture once/job, conservatively charged across jobs. 4MiB/job/32MiB/session checks before publication; atomic publish/release with reference invalidation; TTL clock injectable. No hidden cache. Configured captures count equally. Cursor authenticity uses per-session secret, binding job/collection/size/version; no external key infrastructure.
- jobs.py: `JobManager.submit(operation:Operation,args:ValidatedArgs,deadline:float)->JobAck`, async status/result/cancel/close; one active/8 queued/32 terminal. Deadline includes queue. Own task handle and auxiliary process; one publication lock chooses terminal winner. On worker error/timeout/cancel no usable partial handle. Completion reserves graph then publishes under same terminal transition; rollback reservation if cancellation won. Eviction/expiry/close calls graph release, not just job-ID deletion.
- execution.py: `OwnedProcess.run(kind:Literal['resolve','domain'],payload:BoundedPayload,deadline:float)->BoundedReply`, async cancel_and_reap(). Single auxiliary slot, spawn-safe entry points, bounded IPC. Resolver child uses OS getaddrinfo; <=2s/remaining deadline; domain child calls real synchronous existing algorithms. <=1s terminate/kill/reap grace; late IPC ignored; unreaped child causes fail-closed server shutdown/admission stop. No resolver threads, asyncio.to_thread or overlapping domain/resolver children. Trusted async resolver injection is for controlled boundary tests only; production resolver always this lifecycle. Session-close/disconnect owns process cleanup before result publication.
- security.py: declared `SourceGuard.authorize(url,context:OperationContext)->(normalized_url,tuple[vetted_numeric_ip,...])` rejects origin/scheme/userinfo/ambiguous host and mixed/nonpublic DNS. `GuardedTransport(httpx.AsyncBaseTransport)` validates each request and fixed read-only methods, rejects any nonidentity encoding before decode, reads <=64KiB raw chunks under 2MiB total; redirects manually budgeted/revalidated. `PinnedBackend(httpcore.AsyncNetworkBackend).connect_tcp(host,port,timeout,local_address,socket_options)` resolves through owned resolver and connects only numeric addresses via public AnyIOBackend, preserving HTTP origin and original TLS hostname. No env proxy, private `_pool` patch or second uncontrolled hostname lookup. Tests inject raw wire transport/resolver below guard, never guard decisions. Guard maps blocked address to permission_denied, source DNS failure to source_error. Candidate URL eligibility calls same policy without destination connection; later fetch revalidates DNS.
- sources.py: `GuardedSources.discover(url,max_items,budget)->SourceResult[str]`, `.extract(url,max_items,budget)->SourceResult[Product]`, SourceResult includes items/completeness/diagnostics/captures. HTTP request/page/byte/deadline budget shared through detection/fallback/redirect/candidate screening. Shopify/Woo optional injected client seam preserves default behavior; Magento GraphQL/Shopware/BigCommerce use existing http_client. Reuse existing parsers, response mappings/capture hooks and normalize; feed pure XML/CSV and structured SchemaOrg/OpenGraph operate on guarded bytes when recognized. CSS/browser/LLM path does not run, returns explicit unsupported-mode/source diagnostics. All fixed GraphQL POST strings originate in native parser, never arbitrary client/source mutation. Captures exist before normalization; backend swallowed failures must become diagnostics or source_error, never true-empty success. Full native source list is documented; no uncontrolled top-level extract call.
- domain.py: `DomainAdapter.discover/extract` async sources; `match` existing match_products over authorized immutable catalogs; `changes` real reliable_changes with startup-granted captures and internal report replay bookkeeping; `evidence` authorized exact product/variant graph then scoped existing retrieval. Synchronous work bounded/isolated via execution.py; snapshot data and graph serialized with existing portable converters. Checks configured supplier/order before execution; query does not cause capture or remote writes.
- mcp_server.py: existing skeleton `serve(runtime)` uses official v1 low-level Server list_tools/call_tool and stdio_server; authoritative input validation delegated to runtime (`validate_input=False`). Final handler returns CallToolResult with shared structured envelope and error flag; permitted advertised tools exactly startup config. Final serve uses try/finally to ensure runtime.close on SDK error/cancel/disconnect and maps request cancellation before submit acknowledgement to orphan cleanup. Current scaffold deliberately lacks these behaviors. CLI `python -m shopextract.tools` or console script parses trusted config then calls serve; actionable missing-extra message, protocol-only stdout. Reference client uses SDK ClientSession/stdio_client only, bounded polling/result/evidence flow, no dispatcher shortcut.

Dependency direction: MCP/CLI → runtime → contracts/jobs/state/domain → existing parser/evidence/matching/reliable APIs; sources → guard/pinned backend/owned execution; existing legacy APIs do not import MCP/runtime. No generic plugin/job framework. G3 will assess cohesion/reuse and refine before business logic.
