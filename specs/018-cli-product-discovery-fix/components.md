# Reusable components and ownership

- Public `discover()` remains the shared consumer for CLI discover/extract and native category production paths. Existing platform API discovery short-circuits stay first. Propagate the existing requestedmax through private platform fallback helpers; do not duplicate extraction/orchestration.
- `_discovery_sitemaps` is a private reusable native discovery component: immutable SitemapDiscovery result, stdlibRobotFileParser+defusedxml parser, existing is_non_product_url denylist, caller HTTP client or one owned client. It owns canonical URL/origin/path scope, category sitemap exclusions, dedup/cycles, request/byte counters and operation-aware deadlines. Expose only one async entry point; small private helpers/constants enable direct boundary tests. No catalog/job/store configuration and no merchant-specific paths.
- stop_fallback means authoritative robots denial or exhausted native resource budget. Unsupported/missing source alone permits old known-sitemap/seeder/browser fallback; cancellation/deadline never starts another fallback. Legacy seeder receives requestedmax. Main discover deadline is min existing300s ceiling, positive requested timeout and active operation remaining; native traversal additionally<=30s. Reader uses decoded chunks and elapsed deadline through body consumption.
- Existing UnifiedCrawl structured extraction, capture, normalizer, Product/Variant and quality scorer own Product facts. No synthetic prices or title-only classification. Existing native CLI extraction_data and atomic_json own envelope/file publication. New component does not touch data-format or identity contracts.
- Source/XML limits:12physical HTTPrequests including redirects+robots,10MiB per decoded source,20MiB cumulative, bounded same-origin redirects<=2, max ordered candidate count. Source category/collection leaves provide excluded merchant URLs; directchild URLloc parsing ignores nestedimage loc. Explicit robots-disallowed store/source URLs stop fallback when authoritative. Provided clients remain open; owned client closes on success/error/cancel.

G3 required before implementing stub/integration. No new HTTP/parser dependency or optional service. Deterministic transport fixtures exercise real traversal and native CLI rather than fake reports. External browser boundary can raise if native successful path incorrectly launches it.
