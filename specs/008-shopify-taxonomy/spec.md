## Boundaries and compatibility
Full means all English records in the pinned official release, including non-leaf categories and every declared attribute/value; it does not promise all languages, historical mappings, semantic correctness of upstream metadata, live products in every category or universal correction policies. No inference/training/provider/token use, installs, writes to merchants, source schema authority invention or broader privileges. Product/Variant constructors, ordinary extract/normalize/default exports and existing category API remain compatible. Optional Storefront and updates require explicit opt-in. Review gates are engineering checks, not additional user permission requests.
